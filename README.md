# 五分鐘計時器

純靜態的五分鐘倒數計時器，不用建置，也沒有任何相依套件。

## 使用方式

直接用瀏覽器打開 `index.html` 就能用。

| 操作 | 按鈕 | 快捷鍵 |
|---|---|---|
| 開始／暫停／繼續 | 開始 | 空白鍵 |
| 重設 | 重設 | `R` |

## 功能

- SVG 圓環顯示剩餘進度
- 剩下 30 秒時轉成紅色並發光閃爍，最後 10 秒數字逐秒彈跳
- 時間到會發出提示音，卡片閃爍、錶面搖晃
- 跟著系統的淺色／深色設定切換配色，並依「減少動態效果」設定關閉動畫

## 檔案

- `index.html`：頁面結構與計時邏輯
- `styles.css`：配色、版面與動畫

## 實作說明

每次都用 `endAt - Date.now()` 計算剩餘時間，不靠累加計時器的次數，所以分頁切到背景再回來也不會變慢。要改倒數長度，修改 `index.html` 裡的 `TOTAL` 即可。
